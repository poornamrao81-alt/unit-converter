# 🌡️ Temperature Unit Converter

A simple beginner-friendly Python program that converts temperatures between **Celsius and Kelvin**.

## ✨ Features

* Celsius → Kelvin
* Kelvin → Celsius
* Simple menu-based selection
* Accepts decimal values
* Handles invalid choices

## 🎯 Project Purpose

This project is part of my journey as a beginner in Python programming. I am focusing on understanding the logic behind each program rather than simply copying code.

I plan to continue building small projects like this to strengthen my programming fundamentals step by step.

## ▶️ How to Use

Run the Python file, choose the conversion option, and enter the temperature.
